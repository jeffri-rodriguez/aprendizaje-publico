# Aprendizaje público

Repositorio donde documento mi proceso de aprendizaje en programación,
Desde ingeniería de software rumbo a inteligencia artificial aplicada.

Mi objetivo es fortalecer mis fundamentos mediante práctica, pequeños proyectos,
depuración, pruebas y documentación de lo aprendido.

## Áreas de aprendizaje

- Fundamentos de programación
- Algoritmos y resolución de problemas
- Git y GitHub
- Pruebas y depuración
- Ingeniería de software
- Fundamentos de inteligencia artificial

## Estado

🟡 En aprendizaje y construcción.

Este repositorio contiene ejercicios y proyectos en diferentes niveles de avance.
Que un tema aparezca aquí no significa que lo considere completamente dominado.

## Contenido

La estructura del repositorio irá creciendo conforme avance mi formación.

Cada carpeta puede contener su propio README con:

- objetivo;
- conceptos practicados;
- instrucciones de ejecución;
- resultados;
- dificultades encontradas;
- aprendizajes;
- mejoras pendientes.

## Cómo trabajo

Intento comprender el problema antes de programar, realizar un intento propio,
probar la solución, depurar los errores y explicar lo que construí.

## Uso de IA

Utilizo herramientas de IA como apoyo para estudiar conceptos, recibir pistas,
revisar explicaciones y analizar errores.

Procuro comprobar que puedo ejecutar, modificar y explicar el código antes de
considerarlo parte de mi aprendizaje.
